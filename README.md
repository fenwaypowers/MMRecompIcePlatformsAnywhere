# Majora's Mask Recompiled: Ice Platforms Anywhere

This is a mod for [Zelda64Recompiled](https://github.com/Zelda64Recomp/Zelda64Recomp) that allows ice platforms in Majora's Mask to be spawned on any body of water in the game. In the vanilla game, only certain scenes allow ice platforms to spawn when Link shoots an ice arrow at water (for example: Great Bay Temple). With this mod, you can now create ice platforms anywhere in the game.

NOTE: Ice platforms cannot be created on water that is too shallow.

If you run into any errors, please [open an issue on GitHub](https://github.com/fenwaypowers/MMRecompIcePlatformsAnywhere/issues).
