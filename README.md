# Majora's Mask Recompiled: Ice Platforms Anywhere

This is a mod for [Zelda64Recompiled](https://github.com/Zelda64Recomp/Zelda64Recomp) that allows ice platforms in Majora's Mask to be spawned anywhere. In the base game, only certain scenes (example: scenes within Great Bay Temple) allow ice platforms to spawn when Link shoots an ice arrow at water. With this mod, you can now create ice platforms anywhere in the game.

If you run into any errors, please [open an issue on GitHub](https://github.com/fenwaypowers/MMRecompIcePlatformsAnywhere/issues).
